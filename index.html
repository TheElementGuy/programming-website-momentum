Momentum Robotics: Programming

Do you code? Do you want to? If so, this subteam is for you.

We are the Programming Subteam. We are the brains of the robot. We make it work and do everything we want it to. We do whatever it takes to get a robot working at a competition!

Here at Programming, we do everything related to code. You will control the motors and sensors in order to have our robot score as much as possible.

Our main programming language is Java. If you know this, joining our subteam will be a breeze. If you don’t know Java, we’ll teach it to you. We start with lessons on how to code the robot from October to December. Then, in January, it’s kickoff. Software is independent of hardware, so we get to work immediately. We divide up the work, so you won’t have to code an entire robot yourself.

What we do:

  • Work directly with the robot
    • You code the robot, you test the robot
    • Drive the robot around! (maybe...)
  • Tune the robot to perfection (actually a lot of our job)
  • Work with industry professionals in programming
    • Our programming mentor will help you with anything programming related
  • Build programming skills to help you in industry
    • Own your very own GitHub profile page
  • Use math to solve problems
  • Create a robot that drives on its own
